JS SERVICE — SITE

Ce dossier contient le nouveau site prêt pour GitHub Pages.

Fichiers :
- index.html
- logo.jpg
- tarifs.jpg
- photos des chantiers

Les noms des photos sont volontairement simples (sans accents ni espaces)
pour éviter les problèmes de chargement sur GitHub Pages.

Aucune photo de piscine n'est utilisée.

Pour GitHub :
1. Ouvrir le dépôt JSSERVICE.
2. Upload files.
3. Envoyer TOUS les fichiers contenus dans ce dossier à la racine du dépôt.
4. Commit changes.
5. Dans Settings > Pages, utiliser la branche principale et le dossier / (root).

Le site utilise uniquement HTML/CSS/JavaScript : aucun Jekyll, aucune dépendance externe.
